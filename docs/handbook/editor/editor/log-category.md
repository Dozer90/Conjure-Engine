# log_category.h
<!-- doc-template:header -->

|---|---|
| File Path | `engine/include/conjure/editor/log_category.h` |
| API ↗ | [The editor](../../../api/editor/index.md) |

<p>The editor&#x27;s log category: every message of <code>conjure_editor_core</code>, <code>conjure_editor_ui</code> and the <code>conjure_editor</code> executable goes through <code>LOG_EDITOR</code> (&quot;editor&quot;), so the console panel and the protocol&#x27;s <code>log</code> event can filter it like any other engine category.</p>

## Macros

### `CONJURE_DECLARE_ENGINE_LOG_CATEGORY` {#symbol-conjure-declare-engine-log-category}

```cpp
CONJURE_DECLARE_ENGINE_LOG_CATEGORY(LOG_EDITOR)
```
