- **F392** MINOR, renderer (glTF import). *What range should imported glTF lights without one get, and how should a different wrapT be handled?* **Decided (as recommended, effort S):** B, Derive the range from intensity. range = sqrt(intensity / LIGHT_RANGE_CUTOFF): the distance at which the shader's inverse-square falloff drops to a named cutoff such as 0.01. - **F015** MAJOR, platform. *Should window::content_scale() return the framebuffer-to-window size ratio (as documented) or the OS display scale (as GLFW returns)?* **Decided (as recommended, effort M):** A, Keep the ratio; fix the GLFW backend.
